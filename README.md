# House Price Prediction Using Linear Regression

## Project Overview
This beginner-level machine learning project predicts house prices based on house area and number of bedrooms using Linear Regression.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset
The project uses a small sample dataset containing 15 houses with three columns:
- Area
- Bedrooms
- Price

## Methodology
1. Created and explored the dataset.
2. Separated input features (X) and target (y).
3. Split the dataset into training and testing sets (80:20).
4. Trained a Linear Regression model.
5. Evaluated predictions using Mean Absolute Error (MAE) and R².
6. Visualized actual versus predicted prices.
7. Tested the model on a new house example.

## Results
- MAE: 7,804.61
- R²: 0.99597

**Note:** The dataset contains only 15 observations, with 3 test samples. These metrics are preliminary and do not establish real-world predictive performance.

## Learning Outcomes
This project provided hands-on practice with data preparation, model training, prediction, evaluation, and visualization.

## Future Improvements
- Use a larger, more realistic housing dataset.
- Evaluate performance using cross-validation.
- Compare Linear Regression with other regression models.
